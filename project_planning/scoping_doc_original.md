1.  **Baseball HMM Idea**

**Hidden states represent latent pitcher performance modes (e.g., hot, mediocre, cold/fatigued). Observed pitch metrics — velocity, spin rate, movement, location — are the emissions. Several framing options exist:**

- **Pitcher hot/cold states from pitch velocity sequences (FiveThirtyEight framing)**
- **Third-time-through-the-order penalty — do pitchers degrade in a detectable way late in games?**
- **Pitch type sequencing — latent strategic states driving pitch selection**

**Datasets:**

- **MLB Statcast via [baseballsavant.mlb.com](https://baseballsavant.mlb.com/) — pitch-level data including velocity, spin rate, release position, and location, going back to 2015**
- **`pybaseball` (Python) — `statcast_pitcher(start_dt, end_dt, player_id)` pulls pitch-level data for any pitcher in a date range**
- **`baseballr` (R) — `statcast_search_pitchers()` provides the same functionality**
- **Lahman Database — season-level historical stats, useful for game- or season-level HMMs**
- **Baseball Reference — career/season batting and pitching stats, accessible via both packages above**

**Key existing analyses to reference:**

- **FiveThirtyEight (2017), "Baseball's Hot Hand Is Real" — fitted a 2-state HMM to fastball velocity residuals across all qualified 2016 starters**
- **SABR Journal, "Is a Major League Hitter Hot or Cold?" — HMM on plate appearance sequences to infer batter hot/cold states using the Viterbi algorithm**
- **Truong (2017), "Using HMMs to Explore the Third Time Through the Order Penalty" — 3-state HMM (good/mediocre/bad) using ball/strike/hit outcomes as emissions, fitted with `hmmlearn` in Python**

* **Core question:** Do starting pitchers switch among latent performance modes during a game, and do those modes become more likely to deteriorate late in the outing?
* **Hidden states:** Zg,t in {hot, baseline, cold/fatigued} for pitch t in game g
* **Observed emissions:** Pitch-level statcast metrics such as velocity, spin rate, release position, and location
* **Primary Framing:** “Latent pitcher performance modes from four-seam fastballs within starts”
* **What method this problem solves:** A pitcher’s “true condition” is not directly observed. We only see noisy pitch outcomes and pitch characteristics. A pitcher can look normal for a while, then lose velo and command for 15 pitches, then recover. An HMM is built exactly for this: a sequence of observed measurements generated by an evolving unobserved state. Stan’s HMM documentation describes the core setup as observed outputs y_t generated from hidden categorical states z_t that follow a Markov chain. and the observed data are pitch metrics from Statcast. Baseball Savant’s Statcast search is pitch-level and can be filtered per player and date range; the CSV docs define velocity, release position, and zone/location fields.
* **Why Regression:** Standard regression can model average velocity decline, average location drift, average spin changes. It does not model latent regime switching well. Regression assumes smooth mean structure, not discrete hidden “modes”. Regression also models state persistence; if a pitcher is cold now, he is more likely to stay cold for the next few pitches. HMMs encode this directly through the transition matrix. Lastly, you want posterior probabilities like “there is a 0.82 posterior probability he entered the cold state around pitch 73,” not just a residual line.

**Model Specification**

- Data structure: Let g \= 1, …, G index starts and t \= 1,.., Tg index pitches
- **Restrict to four seam fastballs only for the main model (for simplicity)**
  - Different pitch types are naturally very different. I;m thinking that if we mix all pitch types together, the HMM may discover states that are really just “fastball state”, “slider state”, “changeup state”
  - Four seam fastballs are usually common and consistent
- Pitch type affects speed, spin, movement. Staying with one pitch makes the hidden state story cleaner

- For each pitch define a feature vector yg,t \= \[velo, spin, etc. other features we wanna use \]
  - Let this be pitch t in game g
- Hidden states zg,t in {1, 2, 3}, 1 \= cold/fatigued, 2 \= baseline, 3 \= hot
  - Each pitch is assumed to come from one of 3 underlying modes
  - The model believes two things: 1\. EAch state produces different kinds of pitches and the states persist over time
- Likelihood: Use a gaussian-emission HMM with diagonal covariance (probably for teaching simplicity): Where for metric m
  - Gaussian Emission: Within each hidden state, the observed pitch metrics are modeled with a normal distribution
- Transition model: Interpretation is that states tend to persist, but switches can occur
- Priors: Initial distribution, we can say that most starts begin near the baseline state, but some starts can begin hotter or colder
  - I think that a reasonable assumption is that most starts begin in the baseline state, sometimes a pitcher starts especially sharp, sometimes he starts flat (ex. Set initial distribution to 20% cold, 60% baseline, 20% hot)
- Transition matrix: Use sticky Dirichlet priors, favors self-transitions while still allowing switches.
  - I think it would be weird if a pitcher went hot → cold → hot → baseline → cold on five straight pitches
  - Usually the performance mode should have some persistence, and we should use a sticky prior
  - Apply Dirichelt prior so probabilities add to one

- Concern: Are the hidden states just “subjective”?
  - States are not arbitrary, because the model infers them from repeated patterns in the data (persistent clusters of velocity, spin, movement, or outcomes) and the states are only useful if they improve fit and prediction.
  - We should treat labels like “hot” or “fatigued” as convenient summaries of latent regimes, not as literal ground truth.
  - Estimate posterior uncertainty over these regimes, rather than claiming the states are perfectly real and directly measurable.

**Core Model Assumptions**

1. first-order Markov dependence: current state depends only on previous state.
2. conditional independence given the hidden state and covariates, the emissions are independent across time.
3. same transition matrix across starts for that pitcher-season unless you add a more complex extension.

**Hierarchical Structure**

- Each pitcher has their own HMM parameters, but those pitcher specific params are drawn from a common population distribution
  - For example, one pitcher may have a larger velocity gap between hot and cold states than another
  - One pitcher may be more likely to stay in the same state longer
- For pitcher i, hidden states zi,t in {cold, baseline, hot}
- Emissions: yi,t |zi,t \= k \~ N(mui,k, sigma^2i,k)
- Transition: zi,t | zi,t-1 \~ Categorical(Ai\[zi,t-1, .\])
- Then to make the pitcher level parameters hierarchical: mui,k \~ N(muk pop, tau^2mu,k)

Each pitcher’s state specific mean velocity and spin is centered around a population mean for that state. Do same for transition probabilities

- For simplicity, do hierarchical emissions (not transitions)
- LEt every pitcher have their own hot/baseline/cold emissions means but keep one shared transition matrix across pitchers
- PArtial pooling
- Pitchers all move among the same three latent regimes, but the exact velocity and spin profile of those regimes differs by pitch
